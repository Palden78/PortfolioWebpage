# Palden Tamang — Personal Portfolio

My personal portfolio website, built to showcase my projects, learning journey, and interests in software engineering and cybersecurity.

## About

This is a personal website created to document the things I build, the technologies I work with, and what I learn along the way.

The site uses a fantasy-inspired field journal aesthetic to reflect my interest in exploration, learning, and building things from scratch.

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Motion
* Vercel

## Deployment

The website is deployed using [Vercel](https://vercel.com).

The project is connected to GitHub, so updates pushed to the `main` branch are automatically deployed through Vercel.

## Purpose

This is a personal project and portfolio website. It is primarily intended to serve as:

* A portfolio of my projects
* A record of my learning journey
* A place to experiment with web development and design
* A way to share my work and background
